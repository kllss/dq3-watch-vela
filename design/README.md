# UI 设计稿 v0.1

`ui-mockup.html` —— 勇者斗恶龙 III 手表版的 10 个界面高保真稿。

## 打开方式

直接用浏览器打开：

```bash
design/ui-mockup.html
```

不需要 npm、不需要服务器、没有外部字体/图片依赖。

## 能做什么

| 操作 | 效果 |
|---|---|
| 顶部 tab | 跳到 01–10 任一界面 |
| `12px 网格` | 在每块屏幕上叠加 12px 网格，检查对齐 |
| `结构标注` | 用红色虚线标出 TopBar / Map / Status / Action / Dialog / Menu / Battle 等区块 |
| `高对比` | 提高次要文本与边框对比，检查可读性 |
| 点击任意手表 | 1:1 放大；`Esc` 或点背景关闭 |

## 10 个界面

1. 标题 / 继续
2. 地图 / 探索
3. 对话 / 选择
4. 主菜单
5. 状态
6. 战斗 / 指令
7. 战斗 / 选敌
8. 商店
9. 存档（含损坏态）
10. 暂停 / 冒险笔记

## 重要说明

- 这是**浏览器渲染的设计稿**，不是 Vela 渲染，也不是可运行 RPK。
- 设计稿用了 `display:grid`、`gap`、`linear-gradient`、`backdrop-filter` 等浏览器能力；Vela 不支持这些，落地时必须按 `docs/UI-SPEC-v0.1.md` 第 4 节替换成 flex + margin + 纯色。
- 尺寸是 432×514，和 REDMI Watch 6 一致；但真机字体度量可能略有差异，最终以 M1 实机为准。
- 界面里的怪物/地名/数值是占位内容，不是原作数据；真实数据见 `data/local/raw/`。
- 标题"勇者斗恶龙"是商标；公开版需要改名。

## 评审时重点看

- 11×9 地图是否够看清；
- 对话 3 行 × 20 字是否够读；
- 战斗 5 个指令按钮是否太挤；
- 菜单 2×3 瓦片是否太大/太小；
- 存档损坏态是否足够明显；
- 单手能否完成"地图 → 菜单 → 战斗 → 暂停"。
