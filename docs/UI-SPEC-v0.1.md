# UI 规格 v0.1 · 勇者斗恶龙 III 手表版

- 目标设备：REDMI Watch 6 普通版（432×514，矩形，触屏，表冠）
- 设计稿：`design/ui-mockup.html`（10 个界面，可放大、可叠加 12px 网格/结构标注）
- 前置文档：`docs/GDD-v0.1.md`、`docs/M0-仓库审计报告.md`
- 日期：2026-10-25
- 状态：**设计稿 + 实现规格；未写 Vela 页面代码**

---

## 0. 这份规格解决什么

GDD 回答"游戏怎么玩"，这份规格回答"界面怎么落地"：

1. 每个界面在 432×514 里占多少高度；
2. 每个组件的尺寸、颜色、状态；
3. 哪些设计稿效果 Vela 不支持，必须换实现；
4. 页面如何绑定数据、如何避免重渲染；
5. 真机上要验收哪些 UI 项。

设计稿是浏览器渲染，**不是 Vela 渲染**。两者差异见第 4 节。

---

## 1. 设计原则

| 原则 | 具体做法 |
|---|---|
| 手表优先，不是缩小的主机 UI | 11×9 视野、3 行对话、2×3 菜单、5 指令战斗 |
| 单手可玩 | 主操作在右下；返回/暂停在左上；不需要双手组合键 |
| 一眼能读 | 正文 18px、关键数字 22–24px、次要信息 ≥11px |
| 不依赖隐藏手势 | 所有功能都有可见按钮；表冠只是加速器 |
| 不依赖返回键 | 每个非地图界面有 `‹ 返回`；地图有 `暂停` |
| 高对比 | 深底浅字；不用低对比灰；颜色 + 文字双重编码 |
| 不追求动画 | 不做打字机、不做 60fps；步进刷新，瞬时切换 |
| 状态可见 | 存档损坏、输入锁、忙碌、空槽都有明确文案 |

## 4. Vela 能力边界（设计稿 → 实现）

这一节是"设计稿能画，Vela 不一定能跑"的清单。依据：Vela 通用样式文档、组件文档、M0 实测。

| 设计稿用法 | Vela 支持 | 实现替代 |
|---|---|---|
| `display: grid` | **不支持**；只支持 `flex` | 用"行 div + 子项 div"的嵌套 flex |
| `gap` | **不支持** | 用 `margin-right` / `margin-top`，并在宽度里扣掉 |
| `linear-gradient` | **不支持**（`background-image` 只接受 URI） | 纯色叠加 / 预渲染 PNG / 两层半透明 div |
| `backdrop-filter` | 不支持 | 去掉，用不透明面板 |
| `transform: scale` | 未列出，按不支持处理 | 用实际尺寸；不要靠缩放做选中态 |
| `z-index` | 未列出 | 用 DOM 顺序；后渲染的在上层 |
| `overflow: hidden` | 未列出 | 避免依赖裁剪；圆角容器 + 子元素不越界 |
| `box-shadow` | API 3+ 支持 | 可选；无阴影也能用边框分层 |
| `:hover` / 媒体查询 | 不支持 | 用数据驱动的 class/内联样式 |
| `flex-wrap` | 未列出 | 明确分行，不依赖换行 |
| `position:absolute` | 支持（px，不支持百分比） | 对话框/覆盖层可用；优先 flex |
| `display:none` | 支持 | 用 `if` 控制节点更稳 |
| `text-overflow` | `text` 组件支持 | 单行省略；多行用 `lines` |
| `line-height` | 支持 | 对话 28px |
| `border-radius` | 支持（需 border） | 所有卡片带 1px 边框 |
| 自定义组件 `.ux` | 支持但不建议手表用 | 只用两个页面（标题 + 游戏）；游戏内部纯 JS 模块 |

### 4.1 布局翻译示例

**设计稿（grid）：**

```css
.map { display:grid; grid-template-columns:repeat(11,36px); }
```

**Vela（flex）：**

```html
<div class="map">
  <div class="map-row" for="{{rows}}">
    <div class="tile" for="{{$item}}" style="background-color:{{$item.bg}}">
      <text class="tile-t">{{$item.ch}}</text>
    </div>
  </div>
</div>
```

```css
.map { width:396px; height:324px; flex-direction:column; }
.map-row { width:396px; height:36px; flex-direction:row; }
.tile { width:36px; height:36px; justify-content:center; align-items:center; }
```

**注意**：Vela 的嵌套 `for` 需要 M1 实测；如果内层 `for` 不支持，就把 9 行写成 9 个显式块，或把 99 个格子拍平后用 9 个行容器分配。不要用自定义组件绕过。

### 4.2 菜单翻译

```css
/* 设计稿 */
.menu-grid { display:grid; grid-template-columns:repeat(2,180px); gap:12px; }
```

```html
<!-- Vela：3 行 × 2 列，用 margin 代替 gap -->
<div class="menu-row">
  <div class="menu-tile" style="margin-right:12px">...</div>
  <div class="menu-tile">...</div>
</div>
```

宽度：`180 + 12 + 180 = 372`，在 408 内容宽里居中，左右各 18。

## 6. 屏幕规格

### 6.1 标题 / 继续

**目的**：3 秒内让玩家继续或新游戏。

| 区块 | 高度 | 内容 |
|---|---|---|
| 标题区 | ~150 | kicker 10px、主标题 34px、副标题 12px |
| 按钮区 | 3×56 + 2×10 = 188 | 继续（主选）/ 新游戏 / 设置 |
| 底部 | 18 | 自动存档信息 |

- 有自动存档：`继续` 主选，显示 `Lv12 · 阿利亚罕`；无存档：置灰。
- 点击整行即可，不需要点文字。
- `设置` 可以是次级样式，但不能小到点不到。
- Vela：三段 flex column；不要用绝对定位居中（不同字号会偏）。

### 6.2 地图 / 探索

> 移动模型、相机夹取、右滑规避与手势代码见 `docs/地图移动与手势规避方案.md`；交互演示见 `design/map-movement-demo.html`。

**垂直预算**：12 + 44 + 324 + 40 + 24 + 56 + 12 = 512。

| 区块 | 内容 |
|---|---|
| TopBar | 左 `暂停`、中 地名、右 白天/金币 |
| Map | 11×9，玩家居中；相机夹取 |
| StatusBar | HP/MP（含细条）、Lv、EXP |
| HintLine | 一行 11px 提示；没有提示时留空，不跳高度 |
| ActionBar | 菜单（主选）/ 说话 / 调查 |

交互：

- 点相邻格 → 走一步；不可走 → 一行"走不过去"。
- 点 NPC/门/宝箱 → 直接交互；距离 > 2 格提示"走近一点"。
- 滑动 → 方向；阈值 24px，主轴比 1.5；右边缘 60px 禁用横滑（M1 验证前）。
- `暂停` 永远可点；`菜单` 是主选。

状态：

- 低 HP：HP 数字变 `danger`，不闪烁。
- 中毒/睡眠：名字旁 1 个汉字（毒/眠/麻/乱/封），不用图标字体。
- 输入锁：不显示转圈；按钮短暂变暗 200ms。

### 6.3 对话 / 选择

**布局**：上方 190px 地图残影（55% 不透明度 + 渐暗），下方 306px 对话框。

| 区块 | 高度 | 内容 |
|---|---|---|
| 说话人 | 24 | `gold` 14px |
| 正文 | 84 | 3 行 × 28，18px |
| 翻页符 | 18 | `▼` / `■` |
| 选择 | 52 | 2 个 160×52 按钮 |

- 每页最多 20 全角字 × 3 行；按标点断行。
- 点击对话框任意处 = 下一页；**只绑 `click`**，不要同时绑 `touchend`。
- 出现选择时，翻页禁用；必须点按钮。
- 强制剧情隐藏 `‹ 返回`；普通对话可返回。
- 没有打字机效果；整页瞬时出现。
- 长文本分页，不滚动（滚动会与表冠冲突）。

### 6.4 主菜单

**垂直预算**：12 + 44 + 312 + 14 + 50 + 16 + 12 = 460（余 54）。

- 2×3 瓦片，180×96，间距 12（用 margin）。
- 瓦片内容：20px 单字图标（状/装/道/魔/队/存）、16px 名称、10px 说明。
- 选中：1px `gold` 边框 + 轻微 `panel2` 背景；不用缩放。
- 目标卡：1 行当前目标，虚线金边，11px。
- 底部：金币 + 游戏时间。
- 表冠：滚动/选择由 `scrollY` 决定；点击始终可用。

### 6.5 状态

**垂直预算**：12 + 44 + 76 + 10 + 96 + 10 + 144 + 10 + 20 + 52 + 12 = 486。

- HP/MP 两张卡：10px 标签、22px 数字、细条。
- 属性 3×2：力量/敏捷/防御/智力/运气/性格；每格 ~46px。
- 装备 4 行：武器/防具/盾/头盔；`+值` 用 `hp` 色；空槽用 `sub`。
- EXP 条 + 下一级差值。
- 上一人/下一人 52px。
- 性格只显示名称（如"勇敢"），不显示倍率。

### 6.6 战斗 / 指令

**垂直预算**：12 + 44 + 190 + 48 + 144 + 52 + 12 = 502。

| 区块 | 内容 |
|---|---|
| TopBar | `‹ 撤退`（Boss 隐藏）、回合数 |
| Enemies | 3 张 118×150 卡：2 字缩写、名称×数量、正常/受伤 |
| Message | 1 行 14px，自动前进 700ms，点击跳过 |
| Party | 4×36：名字、HP、MP、细条 |
| Commands | 5×~76×52：攻击（主选）/咒文/防御/道具/逃走（禁用） |

- **敌人不显示精确 HP，也不显示血条**；只显示三档文字。
- 单体目标只有一组时自动选中。
- 长按攻击 = 重复上次指令（QoL）。
- 一回合点击次数目标：杂兵 ≤ 6 次。
- 消息自动前进；点击只跳过当前条，不跳过整回合。

### 6.7 战斗 / 选敌

- 敌方卡缩小到 150 高，保留 2 组。
- 目标行 52 高：`▶` + 名称×数量 + 剩余 + 状态。
- 选中行：金边 + `panel2` 背景。
- 只有一组时直接回战斗指令，不显示此页。
- `取消` 48 高，回指令页。

### 6.8 商店

**垂直预算**：12 + 44 + 290 + 10 + 50 + 52 + 12 = 470。

- 5 行 × 58：名称、价格、增减值。
- 选中行：金边 + 深金背景；买不起/不可装备用 `sub` 置灰，但仍可点开详情。
- 详情卡：1–2 行，说明可装备职业。
- 底部：持有金币 + 购买 132×52。
- 购买后：原地刷新金币/库存；不跳页。

### 6.9 存档

**垂直预算**：12 + 44 + 304 + 10 + 30 + 52 + 12 = 464。

- 4 行 × 70：自动 + 3 手动。
- 每行：槽名、Lv/地点、时间、状态（✓ / · / !）。
- 空槽：`— 空 —`，可写入。
- 损坏槽：红边 + 红字"校验失败，可回退到自动存档"。
- 底部：保存到 1 / 读取 / 删除；删除需二次确认。
- 保存中：按钮禁用 + "写入中…"，不要弹窗。

### 6.10 暂停 / 冒险笔记

**垂直预算**：12 + 44 + 234 + 12 + 100 + 20 + 12 = 434。

- 4 行 × 54：继续 / 冒险笔记 / 设置 / 回标题（危险）。
- 冒险笔记：最近 3–5 条线索，11px，行高 1.8。
- 底部：长按 600ms 回标题提示。
- 暂停不依赖返回键；任何时候都能打开。

## 7. 交互与状态矩阵

与 GDD 4.6 一致，UI 只消费 `Game.mode` 和 `inputLockUntil`：

| 模式 | 可点区域 | 禁用 |
|---|---|---|
| FIELD | 暂停、菜单、说话、调查、地图格 | 对话/菜单按钮 |
| DIALOG | 对话框、选择按钮、可返回时的返回 | 地图/菜单 |
| MENU | 6 瓦片、返回 | 地图 |
| STATUS/EQUIP/ITEM | 行、返回、翻页 | 其他 |
| BATTLE_COMMAND | 5 指令、撤退 | 菜单/暂停 |
| BATTLE_TARGET | 目标行、取消 | 指令 |
| BATTLE_RESOLVE | 点击跳过消息 | 所有指令 |
| SHOP/INN/CHURCH | 行、购买/住宿、返回 | 战斗 |
| SAVE | 4 槽、保存/读取/删除、返回 | 其他 |
| PAUSED | 4 行、返回 | 地图 |
| GAME_OVER | 复活/读档 | 其他 |

规则：

- 模式切换后 200ms 内丢弃输入；
- 同一动作 120ms 去抖；
- 异步操作（存档/切图）期间 `busy=true`，按钮变暗；
- 任何界面都不允许"只能靠返回键退出"。

## 8. 数据绑定与渲染策略

### 8.1 页面只绑"扁平快照"

```js
// Game.snapshot() 返回
{
  mode: 'FIELD',
  top: { left: '暂停', center: '阿利亚罕平原', right: '白天  128G' },
  map: { rows: [ { cells: [ { ch:'#', bg:'wall' }, ... ] }, ... ] },
  status: { hp: 34, hpMax: 34, mp: 6, mpMax: 6, lv: 3, exp: 128 },
  hint: '草丛里传来沙沙声…',
  actions: ['菜单', '说话', '调查'],
  ...
}
```

页面把这些字段直接赋给 `private`：

```js
this.mode = s.mode
this.topLeft = s.top.left
this.mapRows = s.map.rows
this.hp = s.status.hp
...
```

避免：

- 不要把整个 `Game` 对象塞进 `private`（深层 watcher 会拖慢）；
- 不要每帧更新 99 个格子；只在"走一步/切图"时更新；
- 不要在模板里做计算（Vela 模板表达式能力有限）。

### 8.2 地图更新

- `mapRows` 是 9 行 × 11 格的数组；每格 `{ ch, cls }`。
- 走一步：只重算视口内 99 格，赋新数组。
- 切图：整表替换。
- 刷新目标：< 50ms/步（M1 T13）。

### 8.3 文本

- 对话分页在 `core` 里做，页面只拿 `lines: string[]`。
- 每行 ≤ 20 全角字；页面 `text` 设 `lines: 3` 兜底，但不依赖它截断。
- 不用打字机；不做逐字更新。

### 8.4 列表与表冠

- 菜单/商店/存档用 `scroll`，行高固定。
- `onscroll` → `sel = round(scrollY / rowH)`。
- 进入列表 `scrollTo(sel*rowH, instant)`，`suppressUntil = now+250`。
- 退出列表重置 `scrollY/basePending`。

## 9. 可访问性

| 项目 | 要求 |
|---|---|
| 正文 | ≥18px；次要 ≥11px |
| 对比度 | 正文 ≥7:1；次要 ≥4.5:1 |
| 点击目标 | 主操作 ≥52×52；列表行 ≥52 高；地图格 36 + 吸附 |
| 单手 | 主操作右下；返回左上；不需要双手 |
| 颜色 | 不只靠颜色：受伤/正常、中毒/睡眠都有文字 |
| 动效 | 无闪烁；无快速切换；高对比模式可选 |
| 字体放大 | 115% / 130% 作为后续设置；M1 只做 100% |
| 误触 | 删除/回标题二次确认；长按 600ms |
