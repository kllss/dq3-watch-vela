# DQ3 手表版 · M1a

可安装的最小运行原型：**标题页（栈底）+ 游戏页**，假地图、真输入、真存档。

## 现在能做什么

| 功能 | 状态 |
|---|---|
| 标题页读取自动存档，显示 `Lv / 地图 / 步数` | 已实现 |
| 「继续游戏」从存档位置恢复 | 已实现 |
| 11×9 地图、相机跟随与边缘夹取 | 已实现（**一张贴图 + 角色叠加**，不是 99 个格子） |
| 点相邻格移动（容器坐标换算） | 已实现，**坐标精度待真机验证** |
| 方向键移动（↑←→↓，兜底输入） | 已实现 |
| 撞墙 / 下水 / 越界不移动，底部给一行提示 | 已实现 |
| 撞 NPC 弹对话，点一下翻页 | 已实现 |
| 手动「存档」按钮 | 已实现 |
| 游戏中右滑 → 回标题页 → **自动存档** | 已实现 |
| A/B 双槽 + 32 位校验 + gen 递增 | 已实现 |
| 战斗 / 菜单 / 道具 / 咒文 / 真实数据 | 未实现（M2 起） |

## 为什么地图是一张图

第一版每走一步重建 9×11=99 个格子、每格还带一个 `<text>`，手表上明显卡。
现在：

- `tools/map-image.mjs` 在构建前把地图数据渲染成一张 PNG（540×468，2.6 KB）；
- 页面用 `<stack>` 放这张图和「勇」「人」两个文字，靠 `left/top` 平移；
- 走一步只改 4 个数字（图偏移 + 角色坐标），节点数从 ~200 降到 3。

代价：地图改了要重生成贴图（`build.mjs` 已自动调用），包体多几 KB。

## 架构

```
src/
  core/store.js   跨页面共享状态（挂 globalThis，页面销毁后仍在）
  core/save.js    A/B 双槽存档 + 校验
  core/game.js    纯函数：移动、碰撞、相机（不 import 任何数据）
  core/world.js   M1 假地图（15×13，一张）
  Common/map/*.png 预渲染的地图贴图（由 tools/map-image.mjs 生成）
  pages/Title/    栈底：存档摘要、继续/新游戏、回来时自动存档
  pages/Game/     地图、输入、对话、存档按钮
```

**模块规则**：本地 `.js` 模块**不能写 `export`**——编译产物里模块参数被改名成 `__webpack_exports__`，
函数体却仍写 `exports.xxx`，运行时直接 `ReferenceError`，页面黑屏。
所以 core 里的模块都是"副作用模块"：内部定义函数，挂到 `globalThis.__dq3_*_api`；
页面 `import './core/x.js'` 后从 `globalThis` 取。完整证据见 `docs/构建与模块验证.md`。

三条硬规则：

1. **状态不放页面 `private`**：游戏页被系统 pop 会走 `onDestroy`，状态必须活在页面外；
2. **标题页是栈底**：右滑从游戏页退回标题，而不是退出应用（`followHand` 已实测无效）；
3. **构建必须跑哨兵校验**：`build.mjs` 会检查每个模块的 `MODULE_TAG` 是否真的进了页面 bundle，缺了直接失败。

### 为什么有两个输入通道

Vela 的模板**不支持给事件传参**（`onclick="fn({{$item.x}})"` 会直接编译失败，报 `Unsupported Event value`）。所以点格子只能在 `.map` 容器上收一次事件，再用 `$element('map').getBoundingClientRect()` 换算格号。

坐标换算依赖事件对象里有 `clientX/clientY`——这一点**还没在真机上验证**。所以同时保留方向键，点格失效也不影响验证其它功能。

## 构建保护

`node game/build.mjs` 会先删缓存，再打包，然后解包校验：

- 4 个模块标签必须出现在页面 bundle 里（标签是导入时执行的副作用，不会被 tree-shaking 删掉）；
- bundle 里不允许出现 `"./src/xxx.js" () {}` 这种空模块。

任何一条不满足就构建失败。游戏页底部也直接显示 `模块：store save game world`，真机上能一眼看出谁没加载。

## 已知风险

- **点格坐标**：事件字段（`clientX` / `x` / `pageX`）是猜的，T3 会验证；三种都取不到时只在底部提示，不会崩；
- **地图贴图**：`<stack>` + `left/top` 平移的实际观感还没在真机上看过（T3–T5 一起看）；
- **存档键名**：`saveA` / `saveB` 是全局 key，与探针包的 key 不冲突，但同一设备装多个实验包时别用同名 key；
- **应用名**：「DQ3 手表版」是工作用名，公开分发前需要换掉（商标）；
- **包体积**：地图数据在两个页面里各打一份，当前 47 KB + 75 KB；真数据必须改按需读取或拆页面。
